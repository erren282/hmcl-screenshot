# 截图管理 · HMCL 插件

在 HMCL 的**实例管理**页面新增一个「截图管理」标签页，用来浏览当前实例的截图。

## 功能

- 自动定位**当前实例**的 `screenshots` 目录（按实例自己的运行目录解析，不与其他实例混用）
- 以缩略图网格展示，按创建时间从新到旧排列；缩略图保持原图宽高比，不出现黑边
- **点击缩略图**打开预览弹窗
- 每张图右下角悬停出现「⋮」菜单：用图片管理器打开 / 在文件管理器中显示 / 重命名 / 删除
- 「打开截图目录」直接定位到文件夹
- 「刷新」重新扫描（游戏内截图后无需重启启动器）

### 预览弹窗

- **← → 方向键**或两侧箭头切换上一张 / 下一张，不必关掉重开
- 滚轮缩放（Shift + 滚轮也可切换），拖拽移动画面
- 缩放比例在同一会话内记忆，翻页时不再重置
- Esc 关闭

### 多选与批量删除

- **Ctrl + 点击**切换单张选中，**Shift + 点击**选中区间
- 选中后顶部出现操作条，显示数量并提供「删除选中」「取消选择」
- **Delete 键**直接删除选中项，**Esc 清除选择**
- 批量删除只需**一次确认**，不再逐张弹窗

### 性能

- 缩略图在鼠标悬停时才解码，图片多的目录不会一次性卡住页面
- 缩略图按显示尺寸解码，不把 4K 截图整张读进内存

## 安装

1. 下载 Releases 里的 `org.dsh.screenshot_1.5.0.jar`
2. 放入 `.hmcl/plugins/`
3. 重启启动器

打开方式：游戏列表 → 选中实例 → **截图管理** 标签页。

## 实现说明

插件 API 没有「向实例页注入标签页」的扩展点，因此本插件在运行时定位 `VersionPage`，
读取它的 `tab` 字段（`TabHeader`），再通过 `getTabs()` 追加一个 `TabControl.Tab`。

- 类名与字段名都以字符串方式查找，不硬引用启动器内部类型
- 轮询发现新打开的实例页并注入，切换实例后会重新绑定目录
- 停用插件时移除该标签页，启动器恢复原样

## 注意

- 删除与重命名会**真实修改磁盘文件**，删除前有一次确认（批量删除同样只确认一次）
- 停用/卸载插件后标签页消失，属于预期行为
