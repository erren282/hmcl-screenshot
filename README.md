# 截图管理 · HMCL 插件

在 HMCL 的**实例管理**页面新增一个「截图管理」标签页，用来浏览当前实例的截图。

## 功能

- 自动定位**当前实例**的 `screenshots` 目录（实例隔离目录与共享 `.minecraft` 目录都会检查）
- 以缩略图网格展示，按修改时间从新到旧排列
- 点击缩略图用系统看图器打开原图
- 支持按文件名筛选
- 「打开截图目录」直接定位到文件夹
- 「刷新」重新扫描（游戏内截图后无需重启）

## 安装

1. 下载 Releases 里的 `org.dsh.screenshot_1.0.0.jar`
2. 放入 `.hmcl/plugins/`
3. 重启启动器

打开方式：游戏列表 → 选中实例 → **截图管理** 标签页。

## 实现说明

插件 API 没有「向实例页注入标签页」的扩展点，因此本插件在运行时定位 `VersionPage`，
读取它的 `tab` 字段（`TabHeader`），再通过 `getTabs()` 追加一个 `TabControl.Tab`。

- 类名与字段名都以字符串方式查找，不硬引用启动器内部类型
- 轮询发现新打开的实例页并注入，切换实例后会重新绑定目录
- 停用插件时移除该标签页，启动器恢复原样

## 注意

- 只读取文件，不修改或删除截图
- 停用/卸载插件后标签页消失，属于预期行为
